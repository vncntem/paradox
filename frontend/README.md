# PARADOX Website Frontend

The official frontend for [thisisparadox.com](https://thisisparadox.com) - a modern, minimalist landing page with email subscription functionality.

## Features

- Interactive particle background with user interaction
- Dynamic tagline rotation
- Smooth email subscription with animated feedback
- Responsive design
- Modern UI with Paradox brand colors
- Parallax scrolling effects

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- [Particles.js](https://vincentgarreau.com/particles.js/) for background animation
- Google Fonts (Montserrat & Playfair Display)

## File Structure

- `index.html` - Main landing page
- `styles.css` - All styling and animations
- `privacy.html` - Privacy policy page
- `terms.html` - Terms of service page
- `paradox_logo_full.png` - Full Paradox logo
- `paradox_logo.png` - Standard Paradox logo

## Features

### Email Subscription
- Real-time form validation
- Animated submission feedback
- Error handling with user-friendly messages
- Integration with Paradox API

### UI Elements
- Particle background with interactive hover effects
- Dynamic tagline rotation from curated list
- Smooth animations and transitions
- Responsive footer with site navigation

## Brand Elements

### Colors
- Primary: #ff3366 (Paradox Pink)
- Text: #ffffff
- Background: #000000

### Typography
- Headers: Playfair Display
- Body: Montserrat

## Development

The site is hosted on Cloudflare Pages and automatically deploys from the main branch. The subscription functionality connects to our API at `email-api.thisisparadox.com`.
